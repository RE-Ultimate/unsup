# Re:Ultimate source mirror

This repository preserves the unsup source and commit history needed by [Re:Ultimate](https://github.com/RE-Ultimate/Re-Ultimate).
Original authors, copyright notices, and component licenses are retained. This mirror does not change them to MIT.

Pinned binary dependencies are in [RE-Ultimate/maven](https://github.com/RE-Ultimate/maven).
Publishing tasks stage Maven artifacts in `build/reultimate-maven`; review and copy them into that repository when releasing a version.
The original README and release tags remain available for reference.
